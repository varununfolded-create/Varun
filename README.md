# Varun K R — F1 Build Journey Portfolio

A production-ready static portfolio for **Varun K R — Data Analyst · Technical Consultant**, styled as a premium Formula 1 engineering journey.

## Design direction

- Black + deep navy + electric blue palette
- Realistic Formula 1 garage/car imagery in the hero and Race Day sections
- Varun's personal photo appears **once only**, in the hero
- Clean Inter typography (classic/professional rather than condensed racing fonts)
- Blueprint section uses a realistic engineering/garage image instead of placeholder chassis text
- Project visuals for ML predictive analytics and OCR document extraction
- OCR pipeline is explicitly shown as **DOCUMENT → STRUCTURED DATA → EXCEL**
- Data Journal with three long-form articles
- Email visible; LinkedIn and Instagram are icon-only clickable buttons
- Local Race Engineer AI chatbot with profile knowledge
- Guest access + demo recruiter login

## Run locally

No build step is required.

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install/use the Live Server extension.
4. Right-click `index.html` → **Open with Live Server**.

You can also open `index.html` directly in a browser; the portfolio no longer depends on a remote 3D model to show the car background.

## Deploy

### Vercel
Import the folder/repository into Vercel as a static site. No build command is required.

### Netlify
Drag the project folder into Netlify Drop or connect the repository. No build command is required.
